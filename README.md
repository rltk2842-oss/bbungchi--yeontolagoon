# WHO ARE ME? — GitHub Pages용 뿡치 콘텐츠 맞히기

`index.html`, `style.css`, `game.js`, `data.json`을 같은 폴더에 올리면 됩니다.

사이트에 처음 들어올 때 생일 축하 이미지가 팝업으로 표시됩니다. `game.js` 상단의 `BIRTHDAY_IMAGE_DISPLAY` 값을 `'yes'` 또는 `'on'`으로 설정하면 팝업이 열리고, `'no'` 또는 `'off'`로 설정하면 열리지 않습니다. 기본 이미지는 `images/birthday.jpg`이며, `BIRTHDAY_IMAGE_PATH`를 수정하면 다른 이미지로 교체할 수 있습니다. 팝업은 닫기 버튼이나 이미지 바깥 영역을 눌러 닫을 수 있습니다.

GitHub 저장소 → Settings → Pages → Deploy from a branch → `main` / `/ (root)` 선택.

도감에는 연토리뿡치의 공개 방송 기록 중 개별 콘텐츠 URL과 정상 썸네일이 있는 항목만 등록되어 있으며, 현재 총 56개로 구성되어 있습니다. `data.json`의 name, category, type, date, format, adult, guple, url, thumbnail을 수정하면 도감과 문제에 함께 반영됩니다. `adult`와 `guple`은 `O` 또는 `X`로 입력합니다. 정답 팝업에서 url은 SOOP 바로가기로 사용됩니다.

같은 게임이나 시리즈가 여러 방송에 반복된 경우 대표 콘텐츠 한 건만 유지합니다. 현재 분류 체계는 콘텐츠 8개와 구분 15개로 통합되어 있습니다. 썸네일은 `images` 폴더에 640×360 JPEG로 포함되어 있어 외부 이미지 서버가 느려도 안정적으로 표시됩니다.

현재 통계는 서버 없이 브라우저 localStorage에 저장됩니다. 모든 사용자에게 동일한 일일 문제, 서버 통계, 로그인, 관리자 데이터 등록 등을 넣으려면 다음 단계에서 Firebase/Supabase 같은 백엔드를 붙이면 됩니다.

입력한 콘텐츠와 정답의 category, type, date, format, adult, guple 중 같은 값이 있으면 해당 힌트가 자동 공개됩니다. `힌트 보기`는 이미 공개된 항목을 건너뛰고 다음 잠긴 힌트를 엽니다.

자유 게임을 시작할 때 19금 콘텐츠와 구플(구독 플러스) 콘텐츠를 각각 `포함` 또는 `전용`으로 선택할 수 있습니다. 둘 다 미체크하면 해당 값이 `X`인 콘텐츠만, `포함`을 체크하면 `O/X` 모두, `전용`을 체크하면 `O`인 콘텐츠만 출제됩니다. 포함과 전용은 동시에 선택되지 않으며, 다른 문제를 시작할 때도 조건 선택창이 다시 열립니다.

게임 중 도감을 열었다가 뒤로가기를 누르면 진행 상태를 유지한 채 게임으로 돌아옵니다. 정답 팝업을 닫으면 `다른 문제 시작` 버튼이 나타나며, 직전 정답을 제외한 새 문제가 출제됩니다.

콘텐츠 도감의 각 열 제목을 누르면 이름, 콘텐츠, 구분, 방송일, 진행 형태, 19금 여부, 구플 여부를 오름차순·내림차순으로 정렬할 수 있습니다. 도감은 기본적으로 최신 방송일순으로 표시됩니다.

도감의 `보기` 버튼을 누르면 해당 콘텐츠의 썸네일, 방송 정보, SOOP URL과 바로가기 버튼을 팝업으로 확인할 수 있습니다.

입력 기록에는 추측한 콘텐츠의 실제 category, type, date, format, adult, guple 값이 표시됩니다. 같은 값은 초록색, 다른 값은 빨간색으로 표시되며 방송일은 정답이 더 이후이면 ↑, 더 이전이면 ↓로 안내합니다.
